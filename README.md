# cafekai LINEリッチメッセージ画像生成

福岡カフェ会のLINE公式アカウント配信用に、指定期間のイベントCSVから
`1040px × 2080px` のリッチメッセージ用SVG画像を3枚生成します。

## できること

- `--start` と `--end` に日付を入れるだけで、その期間のイベントだけを抽出します。
- 場所別に並べ、同じ日付に複数イベントがある場合は2件目以降の日付を省略します。
- タイトル内容に合わせて絵文字を自動付与します。
- 1枚目は「天神①」、2枚目は「天神②・博多」、3枚目は「全体連絡・その他」の構成で出力します。
- 出力はSVGなので、ブラウザやデザインツールでPNGに変換できます。

## 入力CSV

`sample_events.csv` のように、以下の列を用意してください。

```csv
location,date,weekday,time,title
天神,2026-06-20,土,11:00,３大価値観トークカフェ会
```

## 使い方

```bash
python3 cafekai_campaign.py --events sample_events.csv --start 2026-06-20 --end 2026-06-30 --output-dir output
```

実行後、以下の3ファイルが生成されます。

- `output/page-1.svg`
- `output/page-2.svg`
- `output/page-3.svg`

## 案内文を差し替える場合

3枚目上部の案内文は自動生成されます。任意の文章を使いたい場合は、UTF-8のテキストファイルを作り、
`--notice notice.txt` を付けて実行してください。

## イベントページからの完全自動取得について

`https://cafekai.jp/event` からの直接取得も実装可能です。ただし、サイト側のHTML構造、タブUI、
bot対策、表示タイミングの影響を受けます。そのため、実運用では次の順で自動化するのが安全です。

1. ブラウザ自動操作でイベントページを開く。
2. 指定期間と場所タブごとにイベント情報をCSV化する。
3. このツールで3枚のLINE用画像を生成する。

今回の実装は、まず **日付指定 → CSV抽出 → 画像3枚生成** までを確実に行う土台です。
